# FCS

Нативное приложение для macOS, которое помогает не отвлекаться: на время фокуса блокирует сайты-развлечения (Instagram, YouTube, TikTok и др.) и приложения (Telegram, Spotify). Написано на SwiftUI, без внешних зависимостей.

> Статус: ранняя версия. Используйте на свой страх и риск, а перед тем как отдавать другим людям, проверьте сами.

## Возможности

- Одна кнопка «Начать блокировку» / «Остановить блокировку».
- Таймер: от 15 минут до 4 часов или без ограничения. По окончании блокировка снимается сама, даже если FCS закрыт.
- Свои списки: можно добавлять сайты и любые приложения, списки сохраняются.
- Во время блокировки из списков нельзя удалять, только добавлять.
- Тёмный интерфейс, три экрана: «Фокус», «Блокировки», добавление.

## Требования

- macOS 13 или новее (Apple Silicon и Intel)
- Command Line Tools: `xcode-select --install` (полный Xcode не нужен)

## Сборка и установка

```bash
git clone <адрес репозитория>
cd FCS
./build.sh
```

Скрипт соберёт универсальный `FCS.app`, подпишет его локально (ad-hoc), скопирует в `/Applications` и запустит.

## Как это работает

- **Сайты.** FCS добавляет блок записей между маркерами `# >>> FCS >>>` и `# <<< FCS <<<` в `/etc/hosts` (домены и `www.`-варианты указывают на `0.0.0.0` и `::1`) и сбрасывает DNS-кэш. Для этого macOS запрашивает пароль администратора: при старте, остановке и при добавлении сайта во время блокировки.
- **Приложения.** Пока блокировка включена, FCS завершает процессы с заданными bundle ID в момент запуска и раз в секунду проверяет, что они не запущены. Если выйти из FCS, блокировка приложений перестанет работать (приложение предупредит об этом).
- **Таймер.** При старте с таймером от имени root запускается небольшой фоновый скрипт (`/Library/Application Support/FCS/timer.sh`), который в нужный момент восстанавливает `/etc/hosts`. Поэтому второй пароль в конце не нужен.

## Ограничения

- Браузеры с DNS-over-HTTPS (например, «Безопасный DNS» в Chrome) могут обходить `/etc/hosts`. Отключите эту опцию в настройках браузера.
- Блокировка не защищает от человека, который знает, как редактировать `/etc/hosts` или завершить процесс.
- Приложение не нотаризовано. На чужих компьютерах macOS покажет предупреждение: нужно открыть Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».

## Если блокировка не снялась

```bash
sudo kill "$(cat '/Library/Application Support/FCS/timer.pid')" 2>/dev/null
sudo nano /etc/hosts    # удалите строки между «# >>> FCS >>>» и «# <<< FCS <<<»
sudo dscacheutil -flushcache && sudo killall -HUP mDNSResponder
```

Полное удаление: перетащите `FCS.app` из `/Applications` в корзину и выполните `sudo rm -rf '/Library/Application Support/FCS'`.

## Настройка списков по умолчанию

Стартовые списки лежат в начале `Sources/Store.swift` (`defaultSites`, `defaultApps`). Они применяются только при первом запуске, дальше список хранится в настройках приложения.

## Структура

```
Sources/
  FCSApp.swift   точка входа, окно, выход из приложения
  Store.swift    списки, таймер, блокировка сайтов и приложений
  Views.swift    экраны и окно добавления
  Logo.swift     логотип в виде векторной формы
Resources/
  icon-fcs.icns  иконка приложения
build.sh         сборка и установка
```
